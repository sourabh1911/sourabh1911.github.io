# Sourabh Keragute — Interactive Portfolio

A static, responsive portfolio for Software Engineering, Data Analytics and AI/ML work.

## Included
- Profile, skills, education and internship timeline
- Separate Development/AI and Analytics/BI project groups
- Live demos for IntelliHire and Task & Expense Management REST API
- Zomato Restaurant Analytics GitHub repository
- Dashboard previews and project case-study modals
- Certificate lightbox gallery
- Achievements and contact section
- Dark/light theme, mobile navigation, filters and animations
- Downloadable résumé and T20 project report
- GitHub Pages deployment workflow

## Run locally
No packages or build step are required.

```powershell
python -m http.server 5500
```

Then open `http://localhost:5500`.

On Windows you can also double-click `START_PORTFOLIO.bat`.

## Deploy to GitHub Pages
1. Push this folder to a public GitHub repository.
2. Open **Settings → Pages**.
3. Select **GitHub Actions** as the source.
4. The included workflow deploys on every push to `main`.
